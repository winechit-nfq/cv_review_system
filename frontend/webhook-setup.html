How Auto-Processing Works

1. Upload Detection

When a CV file (PDF/DOCX) is uploaded to a monitored Google Drive folder, our system is immediately notified.

2. AI Analysis

The AI agents automatically analyze the CV against the job description and provide a detailed review with fit score.

3. Auto-Qualification

CVs scoring above 80% are automatically moved to the "qualified_cv_list" folder for your review.

4. Notifications

You'll receive notifications about processed CVs and their qualification status.

Configuration Requirements

Your backend must be publicly accessible (use ngrok for local development)
WEBHOOK_BASE_URL environment variable must be set
Google Drive API credentials with proper permissions
Folder structure: position_folder/cv_list/ and position_folder/job_description/
